# Final Clean GitHub Profile Setup

Upload these files/folders:

README.md
profile_config.json
assets/profile-hero.svg
scripts/update_profile.py

For the hidden .github workflow, create this file manually on GitHub:

.github/workflows/update-profile.yml

Paste the content from WORKFLOW_CODE_COPY_PASTE.txt.

Then enable:

Settings → Actions → General → Workflow permissions → Read and write permissions

Finally run:

Actions → Update Profile → Run workflow
